# CallWise · оболочка в стиле МТС Беларусь

Обновление: голосовой и текстовый разговор уже подключены к локальным Qwen2.5, Whisper
и Silero. Актуальная инструкция и границы интеграции: [LOCAL_AI.md](LOCAL_AI.md).
Описание frontend-only ниже — история первой версии, не текущий статус разговора.

Отдельный frontend-only прототип: HTML, CSS и ES-модули. Без сборки, npm-пакетов,
облачных ресурсов, аналитики, записи микрофона и запросов к AI. Рабочее ядро Callwise не изменено.
Название и оформление МТС используются для неофициального демонстрационного концепта.
Нет официальной авторизации или активации услуг оператора.

## Открыть

В существующей локальной копии уже доступно:
`http://127.0.0.1:8000/static/mts-shell/index.html`

Кабинета в концепте больше нет (P2-02): `#cabinet/...` перенаправляет в рабочий кабинет `/`. Раньше: `#cabinet/agents`. Остальные экраны: `#cabinet/overview`,
`#cabinet/knowledge`, `#cabinet/history`, `#cabinet/settings`.

Независимый запуск из этой папки: `python -m http.server 8001 --bind 127.0.0.1`,
затем открыть `http://127.0.0.1:8001/`. Через file:// ES-модули могут не работать.
Запуск без Python: любой статический HTTP-сервер с корректным MIME для `.mjs`.

## Реализовано

- Главная: фирменная шапка, CallWise, голосовая визуализация, демо, сценарий настройки и FAQ.
- Кабинет: карточки агентов, поиск, фильтры, демо-статусы, обзор и настройки компании.
- Создание агента за три шага с предпросмотром; название, задача, контекст, приветствие.
- Редактирование агента: профиль, тон и темп, контекст, Q&A, будущие каналы.
- Демка: микрофон показывает только состояние UI; текст или готовый вопрос запускают
  заготовленный ответ. Нет getUserMedia, STT, LLM, TTS, звонков или обучения.
- Сохранение завершённых демо-сессий и просмотр расшифровок без аудиозаписей.

Концепт больше ничего не сохраняет в браузере (P2-02). Старые записи с ключом `callwise-mts-shell-v1` не удаляются и читаются только мастером кабинета при явном переносе. Изменения не
синхронизируются между браузерами или коллегами и не затрагивают SQLite ядра.
При недоступном хранилище работает память страницы с предупреждением при сохранении.
Не использовать реальные персональные данные. Статусы, график и примеры не являются
показателями работы реального AI. «Включён» означает только включение в демо-интерфейсе.

## Структура и проверки

- `index.html` — сайт и контейнер кабинета.
- `styles.css` — дизайн, мобильные экраны, reduced-motion.
- `app.mjs` — экраны, формы и UI состояний демо-разговора.
- `adapter.mjs` — отделённый репозиторий, демо-данные, заготовленные Q&A.
- `icons.mjs` — локальные SVG-иконки, без CDN.
- `tests/adapter.test.mjs` — тесты хранения, валидации, escaping, Q&A и ограничений истории.
- `INTEGRATION.md` — точка передачи коллеге и будущий контракт ядра.

Проверки: `node --check app.mjs`, `node --test tests/adapter.test.mjs`.
Прототип доступен через уже существующую раздачу `/static`, новых backend-маршрутов нет.

Визуальные ориентиры: https://www.mts.by/ и https://www.mts.by/corp/.
Демо-источники: https://www.mts.by/help/oplata/proverka-balansa/
и https://www.mts.by/help/internet/nastroiki/.
Это не полный актуальный Q&A МТС: отбор, проверка, версии источников и подключение
knowledge retrieval предстоят на стороне ядра.
