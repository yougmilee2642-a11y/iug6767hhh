# Отдельная задача: качество транскрибации Callwise

Цель — найти причину потери слов и выбрать более качественный вариант распознавания русского при приемлемой задержке на текущем ноутбуке. Не считать заранее, что виновата только модель: проверить запись, endpointing, разрезание на части, сборку текста и само ASR отдельно.

Текущее окружение: локальный Faster-Whisper Small, CUDA int8_float16; NVIDIA RTX 5060 Laptop GPU, 8 ГБ; одновременно на GPU работают Qwen2.5:3b через Ollama и Silero TTS. Не отключать согласие на обработку, не публиковать реальные записи и не менять движок записи на услуги.

1. Зафиксировать исходный звук и эталонный текст на согласованном тестовом наборе, включая длинную фразу с услугой, датой, временем, именем и телефоном. Только вымышленные данные или разрешённые обезличенные материалы.
2. Проверить, теряются ли слова до распознавания, на границах фрагментов или после объединения. Если исходный звук обрезан, замена модели сама по себе его не восстановит.
3. Сравнить несколько кандидатов по сохранению фактов, именам/цифрам/отрицаниям, WER/CER, задержке первого и повторных ответов, VRAM и работе одновременно с LLM/TTS. Не выбирать по одному красивому примеру.
4. Разделить локальные и облачные варианты; отдельно проверить текущие цены, лицензии, ограничения и передачи данных по официальным источникам. Не включать платный/облачный API без выбора владельца.
5. Сохранить контракт: Runtime получает одну окончательную реплику, предварительный текст остаётся подсказкой интерфейса; ошибка фрагмента не становится успешным укороченным текстом. Stop отменяет поздние результаты.

Область работы: `services/local_speech.py`, подсказки транскрибации, клиентская сегментация/сборка, профильные тесты. Изменения общих API согласовать. `agents/booking_language.py`, `agents/booking_dialogue.py`, `agents/runtime.py`, booking tools и их сценарные тесты относятся к отдельной работе над движком.

Итог: воспроизводимый benchmark, причина потерь, сравнение с базовой линией, выбранный вариант с ресурсами/лицензией и проверка через микрофон. Без обещания, что любая речь или весь шум покрыты.
