# Демо 5–7 минут и план презентации

До начала: install, seed, model warmup, свободное окно GPU; две отдельные браузерные
сессии. Время ниже — **сценарный бюджет**, не измеренная скорость модели.
Если модель отвечает дольше, показать ожидание/ошибку и зафиксировать реальное время,
не выдавать ранее созданный результат за новую генерацию.

| Время | Показ |
|---|---|
| 0:00–0:40 | petr/reader: список доступных документов; закрытая смета/встреча → 404; затем irina/manager |
| 0:40–1:20 | Обзор на 11.11: открыто 2, просрочено 1; KPI 90%, 2%, 75%; открыть источник с числителем/знаменателем |
| 1:20–2:10 | Встреча «Задержка фотокниг»: документы, источник и дата загрузки; подготовка с цитатами (требует модели) |
| 2:10–3:30 | Транскрипт → новый draft (требует модели); unknown срок/исполнитель, отклонённое предложение, отмена и injection; открыть U-цитату |

| 5:10–6:10 | QA по материалам с датой и F-источником (требует модели); вопрос про бюджет 2030 → отказ; feedback |
| 6:10–7:00 | Перезапуск, состояние сохранено, reader по-прежнему не видит закрытое; показать аудит и честный отчёт проверки |

Ручной HTTP smoke действительно проверяет подтверждение, обе роли, KPI, QA-отказ
и restart, но **не** заменяет подготовку/генерацию/grounded QA настоящей моделью.
В текущее демо не включать утверждения о выполненном recall до live-отчёта.

## До 10 слайдов

1. Проблема Фотопринт: задержки и потерянные поручения.
2. Путь руководителя: документы → встреча → задачи → контроль.
3. Архитектура и границы remote inference.
4. Подготовка/QA: точные цитаты и отказы.
5. Протокол: решение / предложение / задача / риск / неизвестные поля.
6. Подтверждение человеком, календарь и local_outbox.
7. KPI: формулы, ACL, дата среза, source resolver.
8. Воспроизводимость: данные, gold, lock, CI.
9. Измерения: passed/failed/not run, recall/precision только при настоящем прогоне.
10. Ограничения, лицензии, блокеры и следующая проверка.
