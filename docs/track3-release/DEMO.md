# Демо Фокус v2 — 5–7 минут

Сценарный бюджет, не измеренная задержка модели. До показа пройти
[V2_QUICKSTART](V2_QUICKSTART.md); синтетика привязана к 11.11.2026.
Позднее «сегодня» закономерно помечает данные устаревшими. На контрольную дату:
4 открытые задачи, 3 просрочены; SLA 92%, Mary 68%, прогноз пика 111%.
Это отношения синтетических строк, не измерение настоящей компании.

Две браузерные сессии, отдельная демо-БД. Для AI хост заранее проходит
LIVE_CHECKS; агент этот прогон не выполнял. При отсутствии модели использовать
ручной путь и прямо назвать его ручным.

| Время | Действия и результат |
|---|---|

| 1:30–2:10 | Открыть производственную встречу о задержке фотокниг. Показать документы, реплики, задачи отдела, открытые вопросы прежних протоколов. Добавить пункт в локальный проект повестки; он не сохранён на сервере. |
| 2:10–3:25 | С моделью: подготовка и новый draft, открыть U-цитату. Без модели: показать 503 и сохранённую расшифровку, вручную составить пункт по видимой реплике. Не называть его результатом AI. Неизвестные срок/ответственного не выдумывать. |

Резерв: реплики seed + ручное редактирование и подтверждение. Флаг
`--with-drafts` не реализован. Текст call_defect есть в оценщике, но экран
аналитики звонка, общий чат, кнопка брифинга, метрика→новая встреча и
автоматическая очистка ещё не готовы; не объявлять их работающими.

При remote gateway обработка на машине хоста; Google Fonts остаётся внешним
UI-запросом. Нельзя заявлять полную автономность только по local-only флагу.
План ≤10 слайдов — [PITCH_OUTLINE.md](PITCH_OUTLINE.md).

Дополнительная проверка документов без модели: «Знания» → «Документы · версии
и выдержки» → «Кратко»/источник. У документа владельца раскрыть «Новая версия»,
загрузить изменённый TXT → предпросмотр → отмена (файл остаётся в форме), затем
новый preview → подтвердить → «Версии» → «Сравнить». История и прежние ссылки
сохраняются. ICS/подписки/EML и подбор времени со сменами уже работают локально;
внешней отправки и подключения настоящего календаря нет.
