# Версии документов, выдержки и сравнение

В «Знаниях» раскрыть «Документы · версии и выдержки». Фильтр по названию,
переключатель заменённых версий, исходный файл, «Кратко», «Версии» работают
без модели. Владелец с `documents.upload` может загрузить новую редакцию:
выбрать файл и необязательные даты по Минску → предпросмотр → подтвердить.
Отмена сохраняет выбранный файл в форме и не создаёт документ.

## Правила

- Предыдущий файл, фрагменты и их ID неизменны. Новая запись имеет
  `version+1`, `supersedes_id`, свои фрагменты, дату загрузки и SHA-256.
  Отдел, конфиденциальность, тип и ACL наследуются. Изменить чужой файл через
  версию нельзя, даже если он доступен директору. Admin/auditor не видят контент.
- Preview не создаёт документ: BLOB временно хранится отдельно. Confirm связывает
  файл, права, метаданные, содержимое и фрагменты исходника с предпросмотром.
  Изменения дают409, одновременные confirm создают одну запись. Повтор возвращает
  прежний результат с повторной проверкой доступа. Два preview не создают ветку.
- Поиск/QA по умолчанию исключают версии, у которых есть доступный ассистенту
  потомок. ACL применяется до этого выбора и до FTS5. Невидимая или secret-версия
  не меняет выдачу, предупреждения или статистику ранжирования. История проверяет
  права каждой редакции и скрывает ссылку на недоступного предшественника.
- Контекст встречи использует только явно прикреплённые редакции. Новая версия
  не подменяет материалы других встреч. Если прикреплены обе, для модели берётся
  актуальная. Если оставлена только старая, ответ предупреждает о доступной новой.
  Добавление новой редакции во время генерации не позволяет сохранить старую справку.
- В QA есть «Искать также в прошлых версиях» (`include_history=true`). Обычный
  сохранённый ответ после появления доступного потомка требует обновления (409).
  Исторический ответ остаётся историческим; права, цитаты и текст перепроверяются.
- `valid_until` и даты новых редакций — aware ISO8601; UI вводит Europe/Minsk.
  Истёкший срок не удаляет файл, а даёт предупреждение, также при повторном чтении
  ответа. `Source.source_at` сохраняет договорённость: дата загрузки; дата создания
  документа отображается отдельно в метаданных.

## API

| Маршрут после `/api/meet/documents/{id}` | Действие |
|---|---|
| `POST /versions/preview` | multipart `file`, `authored_at?`, `valid_until?`; confirmation_id и preview |
| `POST /versions/confirm` | JSON confirmation_id, idempotency_key; новая редакция/повтор |
| `GET /versions` | только доступная история; до200 версий, повреждённая цепочка отклоняется |
| `GET /summary` | до5 точных выдержек со ссылками, `model:null`, честное insufficient_data |
| `GET /compare/{other_id}` | diff двух доступных редакций одной цепочки; «Было/Стало» со ссылками |

Отмена — общий `POST /api/meet/confirmations/{confirmation_id}/cancel`.
`/search` принимает query `include_history=true`, `/qa` — JSON bool того же имени.
Неподходящие фрагменты (инъекции, запрещённые запросы, размер вне12..1000) не
становятся выдержками/сравнением. `partial:true` явно помечает пропуски/лимиты.
Diff ограничен2000 исходных фрагментов,50 изменений и5 цитатами на каждую сторону.
Secret не используется в summary/diff; файл владельцу доступен отдельным путём.

## Данные и границы

Миграция13 добавляет таблицу временных файлов и индекс потомков. BLOB удаляется
при confirm/cancel, удалении просроченного confirmation через purge, а также при
следующем preview после истечения срока; максимум10 ожидающих файлов на человека,
каждый до5МБ. Фонового таймера удаления пока нет — остаётся задача E11.5.

«Кратко» — проверяемые выдержки, а не модельный смысловой пересказ. Diff сравнивает
подходящие фрагменты, не доказывает смысловую эквивалентность. Автоматического
поиска противоречий, извлечения обязательств, истории правок протокола, многократной
загрузки документов в одном действии и отдельного редактора всех метаданных нет.
Цепочка ограничена200 редакциями; прототип не рассчитан на многомиллионный архив.

Проверки: `tests/test_document_versions.py`, существующие migration/seed/QA tests,
`v2_http_smoke.py` (включая restart), браузерный путь в `v2_ui_check.py`.
Локальные модели не запускались; браузерный результат нового head проверяется CI.
