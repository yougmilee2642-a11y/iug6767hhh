# План защиты — до 10 слайдов

Содержание без дизайна. Числа качества добавлять только из отчёта соответствующего
commit; синтетику маркировать. Сценарий — [DEMO.md](DEMO.md).

1. Проблема: предновогодний пик, задержка картона, потерянные поручения между отделами.
2. Пользователь: директор/руководитель; отличие от клиентского помощника Mary.
3. Путь: источники → подготовка → протокол → человек → задачи → контроль.
4. Данные: 54 синтетических документа, 5 расшифровок/30 задач, ERP/CRM/Mary-витрины.
5. Показ: источник KPI, поручение с цитатой, cancel/confirm, mock CRM без дубля.
6. Защита: 7 уровней, SQL до модели, admin/auditor без бизнес-содержимого.
7. Техника: FastAPI/SQLite, миграции, privacy, outbox, Linux/Windows CI.
8. Качество: evaluator v2, 36 QA/30 задач на double; live-ячейки пусты до прогона хоста.
9. Ограничения: синтетика, mock-интеграции, незавершённые P1/P2, voice NOT RUN, лицензии.
10. Пилот: сначала производство, затем тестовый Bitrix24; согласовать доступ,
    правовые условия и живой набор оценки до работы с реальными данными.

Экономия времени не измерена. 111%, 92%, 68% — контрольные значения синтетики,
а не результаты внедрения у заказчика.
