# Дневной брифинг

Кнопка «Брифинг» в шапке → дата → «Обновить брифинг».
`GET /api/meet/briefing?date=2026-11-11`; без даты — сегодня в Europe/Minsk.
Чтение требует overview.read. Admin/auditor не получают бизнес-содержимое.

- Личные встречи на выбранный день: владелец, явно указанный участник либо
  участник подтверждённого события календаря. Сервер отдельно проверяет текущий
  доступ к встрече. Чтение отдела само по себе не делает встречу личной.
- Готовность: есть ли прикреплённые материалы, которые может читать ассистент
  пользователя. Чужие/Secret документы не входят даже в счётчик; это проверка
  наличия материалов, не их смысловой полноты.
- Мои задачи: только явный assignee_user_id, открытый статус, срок сегодня или
  просрочен. Отсутствующее назначение не угадывается по имени в тексте.
- Риски подчинённых: активная цепочка manager_id для director/head/lead;
  только доступные через встречу задачи. Риск — срок до завтра включительно,
  high/urgent либо отсутствие срока. Замкнутая цепочка не зацикливает запрос.
- До трёх отклонений: критические прежде предупреждений, затем стабильный ключ.
  Формулы, пороги, источник и актуальность берутся из существующего обзора.
  Это воспроизводимый порядок, не AI-оценка финансового влияния.
- Новые документы: текущие доступные ассистенту редакции за последние семь дней
  до среза, без Secret. Списки ограничены50 строками с явным truncated/предупреждением;
  counts отражает полное количество в доступном scope.

Модель и внешние системы не вызываются, задачи/приглашения/outbox не меняются.
Claims ссылаются на встречи, задачи, проверяемые агрегаты или фрагменты документа.
Каждое открытие источника заново проверяет права; новых копий ответов нет.

Дата выбирает расписание и дедлайны, не восстанавливает прошлые статусы задач
и ACL. Состояние реестров текущее; для выбранной даты KPI берутся не позже конца
дня и текущего времени. Для другой даты есть явное предупреждение. Ошибки
источника, нулевые знаменатели и устаревшие снимки сохраняют предупреждения обзора.

«Озвучить через Фокус» доступно для сегодняшнего брифинга. Текстовый вопрос
«Брифинг дня» / «Что важного сегодня?» использует тот же серверный маршрут без
модели. По умолчанию озвучка разрешена лишь когда всем слушателям доступна
та же короткая фраза; иначе ответ только на экране. Флажок «Я один в комнате»
остаётся явным выбором пользователя. Микрофон и реальный TTS проверяет хост.

Тесты: test_track3_briefing.py; read-only/ACL/роли/Минск/назначения/риски/
источники/ноль/устаревание/длинные списки/voice privacy. Настоящий HTTP и
перезапуск — v2_http_smoke.py, UI кнопка/дата — v2_ui_check.py. Новый browser
прогон зависит от CI: локальный Chromium недоступен по прежней socket policy.
Недельный дайджест, отправка и расписание остаются P2.
